ProWater is a full-stack ops dashboard for a piped RO water business: I modeled
the domain, simulated 24 months of causal data, and built two predictive
workflows — area-level service demand and household churn risk — behind a typed
tRPC API and a server-rendered Next.js UI.

## A note on the data

<Callout type="info" title="Simulated by design">
  All company names, people, payments, and telemetry are simulated. The seed is
  deterministic (`faker.seed(42)`) and anchored to the day it runs, so the
  dashboard’s patterns are real to the dataset, not random rows. Read the [data
  simulation notes](/docs/architecture/data-simulation).
</Callout>
