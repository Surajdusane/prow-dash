## Install dependencies

<Steps>

<Step>

### Add packages

```bash tab="bun"
bun add fumadocs-ui fumadocs-core fumadocs-mdx
```

```bash tab="npm"
npm i fumadocs-ui fumadocs-core fumadocs-mdx
```

</Step>

<Step>

### Configure the plugin

```ts title="next.config.ts"
import { createMDX } from "fumadocs-mdx/next";

const withMDX = createMDX();

export default withMDX(nextConfig);
```

</Step>

<Step>

### Start writing

Create MDX files inside your docs folder:

```bash title="Terminal"
bun run dev
```

Then open [/docs](/docs) to see them.

</Step>

</Steps>
